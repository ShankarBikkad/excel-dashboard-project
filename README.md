# excel-dashboard-project
Excel Bike Sales Dashboard
A beginner-friendly Excel project where I cleaned a bike buyers dataset and built an interactive dashboard to understand who buys bikes.
Dataset
File: Excel Project Dataset.xlsx (about 1,000 customers)
Columns: marital status, gender, income, children, education, occupation, home owner, cars, commute distance, region, age, purchased bike
What I Did
Cleaned the data – removed duplicate rows and checked for errors.
Made the data easy to read – changed short codes to full words (for example, M → Married, F → Female).
Created age groups – used an IF formula to place customers into Adolescent, Middle Age and Old.
Built Pivot Tables – summarized the data by gender, commute distance and age group.
Made charts – created charts from the Pivot Tables.
Built the dashboard – put all charts on one "Bike Sales Dashboard" sheet and added slicers (Marital Status, Education, Region) so the data can be filtered with one click.
Key Insights
Customers with a short commute (0–1 miles) bought the most bikes.
Middle-aged customers made up most of the bike purchases.
Male customers who bought a bike had a slightly higher average income than female customers.
Skills Used
Data cleaning • Excel formulas (IF) • Pivot Tables • Charts • Slicers • Dashboard design
